# Jumpymouse IT Career Services

Custom WordPress theme for [Jumpymouse IT Career Services](https://jumpymouse.com), a veteran-owned business offering IT resume writing, LinkedIn optimization, and career positioning for Linux, cloud, DevOps, and enterprise IT professionals.

## Requirements

- WordPress 6.0+
- PHP 7.4+

## Installation

1. Copy this directory into `wp-content/themes/`.
2. Activate **Jumpymouse IT Career Services** from Appearance > Themes in the WordPress admin.
3. Set your Home, whoami, and Services pages in the WordPress admin, and assign a menu to the Primary Menu location.

## Templates

- `front-page.php` — homepage
- `page-whoami.php` — "whoami" page (Template Name: `whoami`)
- `page-services.php` — services page
- `page.php` — default page template
- `index.php` — fallback template
- `header.php` / `footer.php` — shared layout
- `functions.php` — theme setup, nav menus, asset enqueueing
